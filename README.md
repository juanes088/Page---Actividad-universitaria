# Blog personal

Mi blog personal hecho con HTML, CSS y un poco de JavaScript. Tiene una seccion
sobre mi, las tecnologias que manejo y unos articulos sobre inteligencia artificial.

## Como verlo

Abrir el archivo `index.html` en el navegador.

## Archivos

- `index.html` - pagina principal
- `articulo-1.html`, `articulo-2.html`, `articulo-3.html` - los articulos
- `estilos.css` - los estilos
- `script.js` - el modo oscuro
- `imagenes/` - la foto y los logos
